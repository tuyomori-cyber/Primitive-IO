- テストバージョン: v0.3.0
- 作成日: 2026-09-25
- 対象: Firefox / ChatGPT Web / Dropbox
- 状態: Outputの基本実装と命名ユニットテストは完了。Firefox結合・Network・配布確認は未実施。

## 1. 目的と合格条件

v0.3.0はDropboxの保存先とMarkdownの新規ファイル名を決め、ChatGPTへ保存依頼を投入する。拡張自身は本文・生成結果を取得せず、Dropboxへの書き込みも行わない。

- 保存先はDropbox rootまたは明示選択したフォルダであり、展開操作だけでは変わらない。
- ベース名から大文字・小文字を区別せず既存の.mdを探索し、重複しにくい-vN.mdを決定する。
- 既存下書きを上書きせず、auto-sendは保存依頼を押した場合だけ実行する。
- Dropbox APIで本文取得・アップロード・書き込みをせず、保存成否を表示・記録しない。
- Dropbox/GitHub Inputを回帰させない。

## 2. 実施方法

各ケースをFirefox Desktop上のChatGPT Webで実施し、ID、実施日、Firefox版、結果（OK / NG / Blocked）と、トークンや会話本文を含まない証跡を記録する。実アカウントはテスト専用Dropboxを用い、ChatGPT側Dropbox連携の書き込み可否はPrimitive IOの成功条件にしない。
